## 남은 확인과 구현

- 새 빈 폴더에서 `/company RKLB` 한 줄로 Claude AI 작성·최종 도식·검증·로컬 게시까지 도달하는 경로는 아직 시험하지 못했다. 공개 플러그인의 환경 준비부터 코드 초안 게시까지는 통과했다.
- 새 Claude판은 사용량 한도에 도달해 전체 보고서가 미완료이며 dev에 게시하지 않았다. 검증된 과거 Claude판과 완성된 GPT판만 사이트에서 선택한다.
- 투자 판정 엔진은 요청대로 구현하지 않았다. 모든 결과는 `판정 보류 (v0.1)`이며 투자 프레임워크 v2와 판정 세부 규칙은 후속 입력 대기다.
- Twelve Data Basic에는 배당 이력·실적 발표 일정 API가 제공되지 않는다. 설계의 대체 경로는 SEC 공시·웹 리서치다. 시장 스냅샷의 외부 표시 권한이 확인되기 전에는 숫자를 원격 사이트에 내보내지 않는다.
- 원격 세션의 실제 30일 만료·비밀번호 회전, 다른 기업·비12월 결산, 공시 주석 전체 대조, GitHub 자동 게시·원격 충돌 복구는 미검증이다.
