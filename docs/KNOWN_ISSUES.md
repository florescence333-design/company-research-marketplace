# 알려진 문제와 후속 확인

2026-10-07 현재까지의 실제 실행 결과. 해결 전 항목을 완료로 표시하지 않는다.

공개 플러그인 버전은 0.5.0이다. 아래 0.4.2는 이전 Claude 설치본의 시험 기록이다. 2026-10-07 Codex CLI 새 빈 폴더 리허설은 0.5.0으로 완료했으며, 이번 도식 표시 변경은 공개 저장소 푸시 전까지 로컬·비공개 dev에만 있다.

| 단계 | 항목 | 현재 상태 | 다음 확인 |
| --- | --- | --- | --- |
| 2 | Claude Code 스킬의 슬래시 명령 전체 실행 | 공개 플러그인 0.4.2를 개발 프로젝트 밖 새 빈 Windows 폴더에서 적용해 자체 Python/npm 준비, 기존 기업 SEC 수집, 코드 초안·로컬 게시, 사이트 테스트 13개·SEC 재계산·스키마 검사 통과. Claude Code가 `company`·`company-publish` 스킬을 인식한다. 한 줄의 새 Claude AI 전체 작성은 아직 미시험 | 사용량 한도 재설정 뒤 사용자가 새 폴더에서 명령을 시작해 AI 작성 단계 확인 |
| 2 | Codex CLI 조교 경로 | 공개 0.5.0을 새 빈 폴더에 설치하고 `$company <티커>`로 기존 기업의 SEC 수집부터 로컬 게시까지 약 18분에 완료. CLI 설치가 앱과 별도로 필요하고, `codex.cmd --no-daemon -a on-request -s workspace-write -c sandbox_workspace_write.network_access=true`로 실행했다. CLI 설치가 앱 화면에도 설치됨으로 나타남 | Codex 앱 안에서 `$company <티커>` 직접 실행은 미시험 |

| 3 | 원격 세션 만료·비밀번호 변경 | 운영·dev 새 배포에서 비로그인 차단, 틀린 비밀번호 401/쿠키 없음, 정상 로그인 후 기존 기업 표시 확인. 30일 만료와 실제 비밀번호 변경 시 기존 쿠키 무효화는 원격에서 미검증 | 만료·회전 시나리오를 별도 검사 |
| 4 | 기업·회계연도 확대 | VRT·MSFT의 기간·수치·본문 규칙은 로컬에서 검증했다. 규칙 없는 기업은 본문 네 범주를 누락으로 표시한다 | 다른 결산월 기업과 범용 본문 추출 후속 검증 |

| 5 | 보고서 깊이와 상태 배지 | 개발 GPT판은 비공개 기준 자료와 묶음별 작성을 이용해 16개 대섹션+4-A/B를 검증했으나 기준 보고서 대비 제품별 원가·고객 경제성 등 정량 분석이 부족하다. 조교의 공개 스킬만 사용한 새 폴더 결과는 소제목이 없고 섹션당 2~3문단 수준으로 더 얕다. `작성 완료`는 본문·출처·`[해석]`·반대 논거·검증이라는 **형식 요건** 충족 상태이며 분석 깊이 평가는 아니다 | 다음 버전에서 공개 스킬의 깊이·소제목 지침 강화. 새 Claude판은 S05까지 검증·저장 후 보류 |
