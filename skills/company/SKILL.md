This copies only public runtime files into `.company-research/` in the current folder, creates `.company-research/.venv` with uv-managed Python 3.14, installs `jsonschema`, and installs site packages with npm. `uv` and Node.js/npm must be installed; a preexisting Python or project checkout is not required. Use the `WORKSPACE=` and `PYTHON=` paths printed by bootstrap for every later command. Never execute the workflow from the plugin cache or the developer's checkout, and never depend on its `.venv`. If bootstrap fails, report the exact missing prerequisite instead of guessing a path.

From that prepared workspace, run `scripts/company.py` with its own Python and the current engine (`claude` in Claude Code, `gpt` in Codex). Never print or write its value into a file. Add `--sample` only when the user requests a synthetic example. Never describe a synthetic example as a real analysis.
